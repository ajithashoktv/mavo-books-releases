# Mavo Books

Billing and accounts for small businesses — invoices, purchases, parties, stock, GST returns and
reports, on your own Windows PC.

## Download

**[Download the latest version](https://github.com/ajithashoktv/mavo-books-releases/releases/latest)** —
`MavoBooks-win-Setup.exe`.

Run it and it installs for the current user; there is no administrator prompt. After that the app
updates itself from this page, so this is the only download you need.

## What you need

- Windows 10 version 1809 (October 2018) or later, 64-bit
- About 500 MB of disk space
- An internet connection to activate, and occasionally afterwards; the app keeps working offline in
  between

## Windows will warn you the first time

Until our signing certificate is issued, Windows shows **"Windows protected your PC — Microsoft
Defender SmartScreen prevented an unrecognised app from starting"**. That message means the installer
is not signed yet. To continue: **More info → Run anyway**. Some antivirus products may ask as well.
This page is the only place we publish the installer — do not run a copy from anywhere else.

## Your data

Your books stay on your PC. Backups go wherever you choose in Settings → Backup, and updating the app
never touches your company data.
